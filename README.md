⚽ Doksan Artı: Serie A’yı son düdüğe kadar yaşatan bir web uygulaması

M&Y Yazılım Eğitim Akademi bootcamp’indeki Serie A case’ini bitirdim. Hedefim sadece çalışan bir proje yapmak değildi, açan kişinin bir maçı stadyumdaymış gibi hissetmesiydi.

🏗️ Mimari ve teknolojiler

ASP.NET Core Web API + ASP.NET Core MVC (.NET 8)

SQL Server + Entity Framework Core

SignalR ile gerçek zamanlı canlı skor

Vanilla JavaScript, CSS animasyonları, Canvas API, Web Audio API ve MediaRecorder API

İki ayrı arayüz: halka açık Doksan Artı sitesi ve maçların yönetildiği Teknik Masa admin paneli


📊 Lig ve fikstür

Maç sonuçlarından otomatik hesaplanan puan durumu (puan, averaj, atılan gol sıralaması)

Şampiyonlar Ligi, Avrupa Ligi, Konferans Ligi ve küme düşme bölgeleri

Şampiyonluk ve küme düşme matematiksel olarak kesinleştiği an otomatik kutlama

38 haftalık fikstür, kulüp sayfaları ve takımların son 5 maç formu

Milano, Roma, Torino derbileri ve Derby d’Italia için özel derbi modu


🔴 Canlı maç deneyimi

Admin panelinden skor girildiği anda sayfa yenilenmeden tüm kullanıcılara yansıyor

Stadyumdaki gibi LED nokta matris skor tabelaları

Gol olduğunda tüm ekranı saran, kamera sarsıntılı, ışıkların flaşladığı, kulüp renklerinde konfetili gol anı

Hiç ses dosyası kullanmadan Web Audio API ile sentezlenen stadyum uğultusu ve gol kornası

Maç akışına göre kayan momentum göstergesi

Maça girerken oynayan, tünelden sahaya çıkış animasyonu


🧠 İstatistik ve tahmin

Poisson modeliyle canlı kazanma ihtimali, beklenen gol (xG) ve en olası skorlar

Maç bitince modelin bu sonucu ne kadar beklediğini gösteren “sürpriz sonuç” analizi


Üç olası sonuca göre maçın puan tablosuna etkisi

🎬 Maç sonrası ve paylaşım

Bitmiş her maç için tarayıcıda otomatik oluşturulan, indirilip paylaşılabilen maç özeti videosu

Tek tıkla paylaşılabilir maç kartı

Kaydırdıkça sahne sahne açılan sinematik maç hikayesi


🎨 Tasarım ve erişilebilirlik

Ziyaretçinin saatine göre değişen gündüz, gün batımı ve gece stadyum ışıkları

Hareket azaltma tercihine saygı duyan animasyonlar
